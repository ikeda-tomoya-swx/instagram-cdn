🐯 Claude Code v2.1.131 アップデートまとめ！

2026年5月6日リリースの最新バージョンでは、2つの重要なバグ修正が行われました。

🔧 修正①：VS Code拡張機能のWindows起動問題
バンドルされたSDK内のビルドパスがハードコードされており、Windows環境でcreateRequireポリフィルが正しく動作しない問題を修正。これによりWindowsユーザーもVS Code拡張機能が正常に起動するようになりました。

🔐 修正②：Mantle認証エンドポイントの修正
APIリクエスト時にx-api-keyヘッダーが送信されていなかったため、Mantleエンドポイントでの認証が失敗する問題を修正。認証フローが正常に動作するようになりました。

📦 アップデートはこちら：
npm install -g @anthropic-ai/claude-code@latest
